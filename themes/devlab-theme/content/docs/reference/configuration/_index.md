Theme settings live under `extra.devlab` in `zola.toml`. The pages below describe
individual fields and defaults. [Quick start](@/docs/getting-started/quick-start.md)
provides the initial site configuration.

Landing data is described in [Landing blocks](@/docs/reference/landing.md),
collection inheritance in [Collections](@/docs/reference/collections.md), and
translated labels in [Languages](@/docs/reference/languages.md).

Edit an existing TOML table when adding settings: the same table cannot be
declared twice in one file.
