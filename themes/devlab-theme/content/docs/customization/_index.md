Keep changes in the site's own files so replacing the installed theme does not
remove them.

| Change | Where it belongs |
| --- | --- |
| Name, logo, footer, colors and fonts | [Brand and colors](@/docs/customization/branding.md) |
| Navigation, search and reading controls | [Configuration](@/docs/reference/configuration/_index.md) |
| Stylesheets, scripts and markup | [Template extensions](@/docs/customization/templates.md) |
| Available blocks and their context | [Extension reference](@/docs/reference/extensions.md) |

After changing styles or templates, check the affected pages in both palettes
and at a narrow width. Review those overrides when updating the theme.
