Use Zola 0.23.6. Git is needed for a submodule installation.

1. [Install DevLab](@/docs/getting-started/installation.md) in `themes/devlab-theme`.
2. [Create the first page](@/docs/getting-started/quick-start.md) and run the build.
3. Add the settings your content needs from [Configuration](@/docs/reference/configuration/_index.md).
