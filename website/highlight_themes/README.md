# Syntax theme

`github-dark-high-contrast.json` is the GitHub Dark High Contrast theme from
[shikijs/textmate-grammars-themes](https://github.com/shikijs/textmate-grammars-themes/tree/main/packages/tm-themes/themes),
licensed under MIT (see `LICENSE`). Zola loads it directly, without a package
manager or JavaScript dependency. It keeps directive comments readable on the
website's dark code surfaces.
