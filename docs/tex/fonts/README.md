# Fonts

The typefaces of the Island of TeX visual identity, shipped here so the
books compile with no system installation. They load through `fontspec`
with `Path=fonts/` from this directory.

| Family | Faces | Format | License | Source |
|---|---|---|---|---|
| Karla | Light, Bold, Light Italic, Bold Italic | TTF | SIL OFL 1.1 | [Google Fonts](https://fonts.google.com/specimen/Karla) |
| Rosario | Light, Bold, Light Italic, Bold Italic | TTF | SIL OFL 1.1 | [Google Fonts](https://fonts.google.com/specimen/Rosario) |
| Expletus Sans | Regular, Bold, Italic, Bold Italic | TTF | SIL OFL 1.1 | [Google Fonts](https://fonts.google.com/specimen/Expletus+Sans) |
| Cascadia Code | Light, Bold, Light Italic, Bold Italic | OTF | SIL OFL 1.1 | [microsoft/cascadia-code](https://github.com/microsoft/cascadia-code) |
| Fira Math | ExtraLight, Light, Regular | OTF | SIL OFL 1.1 | [firamath/firamath](https://github.com/firamath/firamath) |

All fonts are licensed under the SIL Open Font License, Version 1.1,
and redistribute freely with the documentation; the license text lives
in [OFL.txt](OFL.txt).
