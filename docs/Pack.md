arara ships with a pack of default rules, placed inside the `rules/`
directory beside the tool itself, as seen in
[Building and deploying](Building.md). This chapter introduces every
official rule, its parameters and one usage example. All of them work off
the shelf, without installation, configuration or modification — and all
of them ship in both rule dialects, so the pack is also the best gallery
of the two formats side by side. In the parameter lists, each entry
carries its own annotation inline: `(boolean switch)` for the natural
on/off options, `(required)` for the ones a rule refuses to run
without, `(default: …)` for the values that apply on silence, and
`(list)` where a list is expected.

# The shared engine options

Many rules in this pack drive a TeX engine, and they share a family of
options, described once here and named per rule below:

- `interaction` — alters the engine's behaviour on errors. When omitted,
  the engine prompts for interaction. The four modes, in order of
  increasing user interaction (courtesy of our master Enrico Gregorio):
  `batchmode`, in which nothing is printed and errors scroll as if the
  return key were hit at every error; `nonstopmode`, in which diagnostics
  appear but no interaction is possible; `scrollmode`, in which the engine
  stops only for missing files or keyboard input, fixing errors itself;
  and `errorstopmode`, in which the engine stops at each error and asks
  for intervention.

- `shell` (boolean switch) — whether running underlying system commands from
  within TeX is activated.

- `synctex` (boolean switch) — whether `synctex`, the input and output
  synchronization feature that navigates from source to typeset material
  and back, is activated.

- `draft` (boolean switch) — whether the draft mode, which produces no output so
  the engine can check the syntax, is activated.

- `branch` (default: `stable`) — allows branching formats for the engine,
  mainly focused on package development: `stable`, the default branch, and
  `developer`, the experimental one for testing documents against upcoming
  releases. Some engines add an `unsafe` branch — at all costs, avoid any
  unsafe invocation with documents off the net or otherwise untrusted.

- `options` — a list of raw command line options appended to the actual
  system call. An error is thrown if the value is not a proper list.

# `animate`

Creates an animated `gif` file from the current file's base name with a
`pdf` suffix, using the `magick` utility from the ImageMagick suite.

- `delay` (default: `10`) — ticks before the next still frame displays.
- `loop` (default: `0`) — repetitions; zero repeats forever.
- `density` (default: `300`) — canvas resolution when rendering vectors
  into rasters.
- `program` (default: `magick`) — the command utility path.
- `options` — raw options, as ever.

```tex
% arara: animate: { delay: 15, density: 150 }
```

# `asymptote`

Executes `asy`, the Asymptote descriptive vector graphics language for
technical drawings. Make the `.asy` extension known to arara to compile
Asymptote files, and use the `files` parameter from your regular TeX
document to include all graphics intended for it.

- `color` — the color model: `bw`, `cmyk`, `rgb` or `gray`.
- `engine` (default: `latex`) — the underlying TeX engine: `latex`,
  `pdflatex`, `xelatex`, `lualatex`, `tex`, `pdftex`, `luatex`,
  `context` or `none`.
- `format` — converts each output file to the specified format.
- `output` — an alternative output directory or file name.
- `options` — raw options.

```tex
% arara: asymptote: { files: [ mydrawing.asy ] }
```

# `authorindex`

Calls the `authorindex` wrapper, a Perl script that processes auxiliary
files generated by the package of the same name, producing author index
files with the `ain` extension.

- `draft` (boolean switch) — writes reference labels and page numbers as comments,
  aiding manual edits of the generated index.
- `index` (boolean switch) — creates a file suitable for `makeindex` and friends.
- `keep` (boolean switch) — retains the temporarily generated `bst` file.
- `print` (boolean switch) — prints the result to standard output instead of a
  file.
- `recurse` (boolean switch) — automatically processes auxiliary files of included
  files. On by default.
- `options` — raw options.

```tex
% arara: authorindex: { draft: yes }
```

# `bib2gls`

Executes `bib2gls`, which extracts glossary information from a `bib`
file into glossary entry definitions, on the current file's base name.

- `dir` — the directory for auxiliary files; the working directory is
  unchanged.
- `trans` (default: `glg`) — the transcript file extension.
- `locale` — the preferred language resource file, as a valid IETF tag;
  `bib2gls` derives the default from the JVM.
- `group` (boolean switch) — whether letter groups are determined and added when
  sorting. Off by default.
- `interpret` (boolean switch) — whether the interpreter mode converts LaTeX
  markup in sort values to Unicode. On by default.
- `breakspace` (boolean switch) — whether the interpreter treats a tilde as a
  non-breaking space. On by default.
- `trimfields` (boolean switch) — whether leading and trailing spaces are trimmed
  from field values. Off by default.
- `recordcount` (boolean switch) — whether record count fields are added. Off by
  default.
- `recordcountunit` (boolean switch) — whether unit record count fields are added.
  Off by default.
- `cite` (boolean switch) — whether citations in the `aux` file are treated as
  ignored records. Off by default.
- `verbose` (boolean switch) — extra information to the terminal and transcript.
  Off by default, and unrelated to arara's own verbose mode.
- `merge` (boolean switch) — whether `wrglossary` counter records are merged. On
  by default.
- `uniscript` (boolean switch) — whether superscripts and subscripts use Unicode
  characters when available. On by default.
- `packages` — a list of packages the interpreter should assume.
- `ignore` — a list of packages to skip when parsing the log file.
- `custom` — a list of package files for the interpreter to parse.
- `mapformats` — a list of two-element lists setting the precedence for
  partial location matches.
- `options` — raw options.

```tex
% arara: bib2gls: { group: true }
% arara: --> if found('aux', 'glsxtr@resource')
```

# `clean`

Removes the provided file reference through the underlying system
command — `rm` on Unix, `del` on Windows. As a security lock, the rule
always errors when the current file equals the original reference, so
the main file cannot be removed; the lock applies to extension-based
removals as well. The `files` parameter is the recommended way to name
the removal candidates.

- `extensions` — a list of extensions; each is appended to the current
  file's base name, building one removal command per pair. With `files`,
  the result is the cartesian product of base names and extensions.

```tex
% arara: clean: { extensions: [ aux, log ] }
```

{% <devlab.callout type="warning" title="Better safe than sorry"> %}
When in doubt, `--dry-run` is your friend: the run goes through all the
motions without the actual calls, so you can watch the removal commands
before any file is lost. And as good practice, keep your `clean`
directives plain, simple and understandable.
{% </devlab.callout> %}

- `ctx` — the `ctx` file for process management specification.
- `interface` — the user interface.
- `autopdf` (boolean switch) — whether the corresponding `pdf` file is closed in
  the viewer and reopened afterwards.
- `purge` — purges files according to the rule: `partial`, `all` or
  `result`.
- `modules` — a list of modules and styles to load.
- `environments` — a list of environment files to load first.
- `mode` — a list of modes to enable for conditional processing.
- `path` — a list of paths consulted during file lookup.
- `arguments` — variables consulted during a run, as key/value pairs.
- `trackers` — a list of tracker variables.
- `directives` — a list of directive variables.
- `silent` — a list of log categories to disable.
- `errors` — a list of errors to show at the end of a run.
- `synctex` (boolean switch) — the shared option.
- `interaction` — the shared option.
- `options` — raw options.

```tex
% arara: context
```

# `datatooltk`

Runs `datatooltk`, which creates `datatool` databases in raw format
from several structured data formats, in batch mode. The rule requires
`output` and one of the import options.

- `output` (required) — the database name to save; the tool forbids the
  `tex` extension for output files, guarding against overwriting a
  document.
- `csv` — imports data from the provided `csv` file.
- `sep` — the value separator of the `csv` file; defaults to a comma.
- `delim` — the value delimiter; defaults to a double quote.
- `name` — the label reference of the newly created database.
- `sql` — imports from an SQL database, the value being a `select`
  statement.
- `sqldb` — the SQL database name.
- `sqluser` — the SQL user name.
- `noconsole` (default: `gui`) — the password request action when no
  console is available: `error`, `stdin` or `gui`.
- `probsoln` — imports data in the `probsoln` format.
- `input` — imports data in the `datatool` format.
- `sort` — sorts by the column whose label is provided, preceded by `+`
  or `-` for ascending or descending order.
- `sortlocale` — sorts by the alphabetical rules of the locale; `none`
  sorts by non-locale letter order.
- `sortcase` (boolean switch) — case-sensitive comparison for non-locale ordering.
  Off by default.
- `seed` — the random generator seed; an empty value clears it.
- `shuffle` (boolean switch) — whether the database is shuffled, always after
  sorting.
- `csvheader` (boolean switch) — whether the `csv` file has a header row.
- `debug` (boolean switch) — whether the tool's debug mode is on.
- `owneronly` (boolean switch) — read and write permissions for the owner only
  when saving `dbtex` files; no effect on some systems.
- `maptex` (boolean switch) — whether TeX special characters are mapped when
  importing from `csv` or SQL.
- `xls` — imports from a Microsoft Excel `xls` file.
- `ods` — imports from an Open Document Spreadsheet `ods` file.
- `sheet` — the sheet to select from the workbook or spreadsheet, an
  index or a name.
- `filterop` — the logical operator for filters: `or` (default) or
  `and`.
- `filters` — a list of filters, each a three-element list of key,
  operator and value.
- `truncate` — truncates the database to the provided number of rows.

```tex
% arara: datatooltk: {
% arara: --> output: books.dbtex,
% arara: --> csv: booklist.csv }
```

# `ghostscript`

Runs `ghostscript`, the interpreter for PostScript and Portable Document

- `program` (default: `gs`) — the command utility path.
- `options` (required) — raw options.
- `device` — the output device; the default is usually a display device.

```tex
% arara: --> output: output.pdf,
% arara: --> device: pdfwrite }
```

# `indent`

Runs `latexindent`, a Perl script that indents TeX files according to an
indentation scheme — environments with alignment delimiters and commands
that split braces across lines are usually handled correctly.

- `silent` (boolean switch) — no output to the terminal.
- `overwrite` (boolean switch) — whether the current file is overwritten; a copy
  is made before the indentation when active.
- `trace` — the tracing level: `default` or `complete`; the detailed
  level significantly affects performance on large files.
- `screenlog` (boolean switch) — whether the log is echoed to the screen as well.
- `modifylinebreaks` (boolean switch) — whether line breaks are modified according
  to a configuration file.
- `cruft` — the location for backup and log files; the working directory
  by default.
- `logfile` — the name of the generated log file.
- `output` — the output file name; it takes priority over switches like
  `overwrite`.
- `options` — raw options.
- `settings` — the indentation settings: `local`, which looks for a
  settings file beside the current file — a location optionally set with
  `where`, otherwise the rule errors — or `onlydefault`, which ignores
  any local configuration.
- `where` — the settings file location; only valid with `settings:
  local`.
- `replacement` — the replacement mode: `full`, `noverb` or `noindent`.
- `check` — checks the indented text against the original: `standard` or
  `verbose`.
- `lines` — the line ranges to operate on.

```tex
% arara: indent: { overwrite: yes }
```

files, and use the `files` parameter from your regular TeX document for
all graphics intended for inclusion.

- `interaction` — the shared option.
- `numbersystem` — the arithmetic for calculations: `scaled`, 32-bit
  fixed-point; `double`, IEEE 64-bit floating-point; `binary`, like
  `double` without a fixed-length mantissa; or `decimal`, arbitrary
  precision in base 10.
- `options` — raw options.

```tex
% arara: metapost: { files: [ graphics.mp ] }
```

```tex
% arara: mkdir: { target: 'dir_to_make' }
```

# `move`

Moves the current file to the provided target with the underlying
operating system move operation. The target is always overwritten, but
an error is thrown when the move would overwrite the original reference.

- `target` (required) — the target of the move operation.

```tex
% arara: move: { files: [ 'thesis.pdf' ],
% arara: --> target: 'backup/thesis.pdf' }
```

# `pdfcrop`

Runs `pdfcrop`, the utility that calculates and removes empty margins,
on the current file's base name with a `pdf` suffix.

- `output` — the output file; the input base name with a `-crop.pdf`
  suffix when omitted.
- `verbose` (boolean switch) — verbose mode.
- `debug` (boolean switch) — debug mode.
- `engine` — the underlying TeX engine for the run: `pdftex`, `xetex`
  or `luatex`.
- `margins` — a list of exactly four elements: left, top, right and
  bottom margins.
- `clip` (boolean switch) — whether clipping support is included when margins
  are set.
- `hires` (boolean switch) — whether the high resolution bounding box is used.
- `ini` (boolean switch) — whether the `initex` variant of the engine is used.
- `restricted` (boolean switch) — whether the tool runs in restricted mode.
- `papersize` — the paper size; for older `ghostscript` versions only.
- `resolution` — the resolution forwarded to the underlying
  `ghostscript` call.
- `bbox` — a list of exactly four elements — left, bottom, right and top
  — overriding the bounding box found by `ghostscript`.
- `uncompress` (boolean switch) — whether the output is an uncompressed Portable
  Document Format, useful for debugging.
- `options` — raw options.

```tex
% arara: pdfcrop
```

# `pythontex`

Runs `pythontex`, the wrapper providing access to Python from within
TeX documents, on the current file.

- `encoding` — the encoding of the document and related files; Unicode
  when unspecified.
- `errorcode` (boolean switch) — whether an exit code of 1 is returned on errors;
  on by default, but sometimes unwanted in editors.
- `runall` (boolean switch) — whether all code is executed regardless of
  modification; useful when a dependency changed.
- `rerun` — the threshold for reexecuting code: `never`, `modified`,
  `errors`, `warnings` or `always`.
- `hashdependencies` (boolean switch) — whether dependencies are checked via
  hashes or modification times.
- `jobs` — an integer for the maximum number of concurrent processes;
  the number of CPUs by default.
- `verbose` (boolean switch) — whether more output information is provided,
  including a list of launched processes.
- `options` — raw options.

```tex
% arara: pythontex: { jobs: 2, verbose: yes }
```

# `texcount`

Runs `texcount`, the Perl script counting words in TeX and LaTeX files,
ignoring macros, tables, formulae and more, on the current file. The
script is highly configurable.

- `rules` — the counting rules: `relaxed` or `restricted`.
- `verbosity` — an integer level from `0`, no parsing details, through
  `4`, which includes parsed words, marked formulae, ignored text,
  comments, options and internal states.
- `strict` (boolean switch) — whether undefined rule groups raise warnings.
- `html` (boolean switch) — whether the report is output in HTML.
- `total` (boolean switch) — whether a total sum replaces the partial, per-file
  sums.
- `unicode` (boolean switch) — whether Unicode is selected for input and output.
- `output` — the output file for the report.
- `options` — raw options.

```tex
% arara: texcount: { output: report.txt }
```

# `texindy`

Runs `texindy`, the `xindy` indexing variant focused on LaTeX documents,
on the current file's base name with an `idx` suffix, generating an
`ind` file.

- `quiet` (boolean switch) — whether progress messages are suppressed; error
  messages always appear.
- `codepage` — the encoding for letter group headings and internal
  sorting.
- `language` — the language whose module dictates the index sorting
  rules.
- `markup` — the input markup for the raw index: `latex`, `xelatex`
  (UTF-8 without `inputenc`) or `omega` (Omega's notation).
- `modules` — a list of module names, searched in the usual application
  path.
- `input` (default: `idx`) — the input file extension.
- `output` (default: `ind`) — the output file extension.
- `log` (default: `ilg`) — the log file extension.
- `options` — raw options.

```tex
% arara: texindy: { markup: latex }
```

# `texfmt`

Runs `tex-fmt`, the fast LaTeX formatter written in Rust, on the current
file.

- `check` (boolean switch) — only checks formatting, without modifying files.
- `print` (boolean switch) — prints the result to standard output, without
  modifying files.
- `messages` — the verbosity of emitted messages: `verbose`, `quiet` or
  `trace`.
- `tabs` (boolean switch) — whether tabs replace spaces for indentation; see
  `tabsize`.
- `stdin` (boolean switch) — processes the standard input as a single file,
  redirecting the result to the standard output.
- `config` (boolean switch) — whether a configuration file is used; the path is
  set with `location`.
- `location` — the configuration file path; requires `config`, or the
  rule errors.
- `wrap` (boolean switch) — whether long lines are wrapped; see `length`.
- `length` — the line length for wrapping; requires `wrap`, or the rule
  errors.
- `tabsize` — the number of characters for a tab.
- `options` — raw options.

```tex
% arara: texfmt: { wrap: yes, length: 75 }
```
